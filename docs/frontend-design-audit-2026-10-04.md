# 泰和乡土手记：前端设计自检

日期：2026-10-04。设计方向：真实地方影像与中文刊物排版。Awwwards、Webby Awards、FWA 作为设计品质参考，本次不复制具体获奖站点的布局，也不代表获得这些奖项的评审认证。

## 原创性与视觉自检

| 维度 | 最终处理与检查 |
| --- | --- |
| 原创性 | 以泰和河岸、街巷与地方书写组织内容；刘字印记、编号索引、中文句读和影像图注构成统一识别。保留博客真实阅读流程。 |
| 排版 | 中文衬线用于标题和长文，无衬线用于导航与操作；标题、摘要、正文、日期采用不同字号与行距。固定字号按断点切换，无负字距。 |
| 留白 | 全幅照片首屏、无外框的阅读区与全宽主题色带；主文与后续文章采用不同节奏。移除原先拥挤的左右文章长列。 |
| 层级 | 首页区分刊名、最新主文、文章网格、主题和作者；档案以年份与缩略图定位文章。文章正文、目录和互动区各有清楚的位置。 |
| 色彩 | 中性白、炭黑、朱红与照片自然色；深色主题区和页脚采用浅色文字与白色键盘焦点。修正后台搜索弹窗的低对比问题。 |
| 动效 | 首屏文字分段进入、照片轻微收拢、内容进入视区渐显；图片与箭头提供悬停反馈。支持 prefers-reduced-motion，观察器在组件卸载时断开。 |
| 微交互 | 原生模态搜索支持焦点约束与 Escape；手机菜单打开后聚焦导航，关闭后返回按钮，切回桌面释放滚动。阅读进度从加载后的 0% 正确更新，位于固定导航上方。 |
| 响应式 | 首页、档案、作者、文章页分别检查 320、390、768、1440、1920 px，共 20 组；未发现横向溢出、标题或控件裁切、已加载图片损坏。 |
| 影像 | 六张实拍，其中五张为可核对的泰和风景、田野与街道，一张为明确标注拍摄地的丝羽乌骨鸡品种参考。提供本地 WebP、多尺寸资源、摄影者、许可与原始出处；自定义文章封面保留。 |

## 修订记录

1. 重建首页首屏、主文、文章网格、主题、作者和页脚，统一文章与档案的阅读样式。
2. 精简重复字体字重，生产 CSS 从约 1.06 MB 降至约 0.56 MB，约减少 47%；图片按显示尺寸加载，手机首屏照片约 29 KB。
3. 将手机档案页的大型标签列表改成主题选择菜单，使首屏露出文章列表。
4. 修复共享搜索弹窗的后台对比度、手机菜单切换宽度后的滚动锁定、菜单键盘焦点，以及阅读进度条层级与异步初始化问题。
5. 检查真实素材对应关系，增加苑前街道实拍，减少封面重复，集中提供影像出处。
6. 统一移动浏览器主题色与朱红站点图标；图标改为稳定的公开路径，与站点 manifest 一致。
